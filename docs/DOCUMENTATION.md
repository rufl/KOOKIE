# Documentation policy

[Português (Brasil)](../pt-BR/docs/DOCUMENTATION.md)

Every public page and document has two maintained forms:

- English: the canonical path under `README.md` or `docs/`.
- Brazilian Portuguese: the matching path under `pt-BR/` or `pt-BR/docs/`.

When changing a document, update both forms in the same commit. Preserve links to measured evidence, source pins, command output, and proof limits. Do not translate code identifiers, file paths, command names, hashes, or upstream product names.

The root README is the landing page. It links to the English document set and the Portuguese mirror. `CONTRIBUTING.md` defines the verification gate required before every push. The active bounded G0 sequence is tracked in [G0_BACKLOG](G0_BACKLOG.md); its resource-token and scalar-adapter contracts are [G0_RESOURCE_TOKENS](G0_RESOURCE_TOKENS.md) and [G0_SCALAR_ADAPTER](G0_SCALAR_ADAPTER.md).
